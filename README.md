# HEALTH PREDICT AI 

## About the Project

Health Predict AI is an intelligent symptom-based disease prediction system.
It allows users to enter their symptoms and provides possible disease predictions
along with confidence levels and recommended precautions.

## Features

- Symptom-based disease prediction
- Disease confidence score
- Recommended precautions
- Symptom description and information
- Easy-to-use interface

## Technologies Used

- Python
- Machine Learning
- Pandas
- NumPy
- Scikit-learn

## Project Files

- app.py – Application interface
- main.py – Main program
- model.pkl – Trained machine learning model
- ranking.py – Disease ranking logic
- symptom_Description.csv – Symptom and disease descriptions
- symptom_precaution.csv – Recommended precautions
- symptom_order.json – Symptom information
- app_backup.py – Backup application file

## How to Run

1. Clone this repository.
2. Install the required Python libraries.
3. Run the application using Python.
